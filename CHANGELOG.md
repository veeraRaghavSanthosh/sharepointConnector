# Changelog

All notable changes to the SharePoint Connector library will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- TypeScript usage example with comprehensive API demonstrations
- JavaScript usage example with both callback and promise-based patterns
- Unit tests for core API functionality and error handling
- Promise wrapper utility for modern async/await usage
- Type definitions and interfaces for TypeScript support
- Advanced examples showing pagination and file operations
- Comprehensive error handling examples
- Documentation for all major API methods

### Enhanced
- Better code organization with separate example files
- Improved error handling patterns in examples
- Added cleanup procedures in sample code
- Enhanced testing coverage for API methods

### Documentation
- Added detailed TypeScript example (`examples/typescript-example.ts`)
- Added comprehensive JavaScript example (`example.js`)
- Created unit test suite (`test-api.js`)
- Improved inline code documentation with type hints

## [Previous Versions]

### [1.0.0] - Initial Release
- Basic SharePoint Online connectivity
- CRUD operations for SharePoint lists
- CRUD operations for list items
- Support for NTLM, Basic, and SAML authentication
- File upload and download capabilities
- User information retrieval
- Pagination support for large datasets
